Getting started

  1. Create a project — a numbered workspace folder (1. Tender Documents … 10. Exports & Archive) and a project CLAUDE.md are created automatically.
  2. Put the tender documents in 1. Tender Documents and press Index documents on the project's Workspace tab.
  3. Import the BOQ (human-measured quantities) from the BOQ template, then map items to assemblies.
  4. Rates: open Rate updates to import a price list or public dataset as candidates, review them, and approve. Missing rates go to Procurement & RFQs.
  5. Check the project's Completeness tab, run reconciliation, and obtain the human approvals needed to release a submission-ready export.

The optional demonstration project is clearly marked SYNTHETIC: run python -m app.cli demo.
