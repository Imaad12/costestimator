# Public data

Nothing has been copied into this folder. The source research (see `../sources/source_register.csv` and `../sources/ACCESS_LOG.md`)
found **no free, legitimately reusable source of SAR unit rates**. Official indices (e.g. GASTAT Construction Cost Index) can be
ingested as *Official Index or Benchmark* records - they are never treated as unit prices.
Place downloaded datasets here (CSV/XLSX/JSON, one file per dataset) and stage them with *Settings -> Rate datasets* or
`app.imports.datasets.stage_rate_dataset`. Every dataset needs a Source Register entry.
